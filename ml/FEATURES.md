# Словарь признаков Neura

## Вход обученной модели

Одна строка соответствует одному ребёнку с детской формой SRS или SRS-2, которую заполнил родитель. Порядок фиксирован. Все пять полей — целочисленные сырые баллы. Пропуск любой шкалы исключает строку. Т-баллы и ответы на вопросы Neura нельзя передавать вместо этих значений.

| Поле ABIDE II | Что измеряет шкала |
|---|---|
| srs_awareness_raw | Распознавание социальных сигналов |
| srs_cognition_raw | Интерпретация социальных сигналов |
| srs_communication_raw | Социальная коммуникация |
| srs_motivation_raw | Мотивация к социальному взаимодействию |
| srs_mannerisms_raw | Характерные повторяющиеся формы поведения |

`srs_total_raw` проверяет согласованность суммы и служит входом отдельной базовой модели. Для ABIDE I аналогичное поле называется `SRS_RAW_TOTAL`. Целевая переменная — код центра `dx_group`, где 1 означает группу РАС, 2 — группу сравнения. Для обучения они переведены в 1 и 0. `age_at_scan` используется для отбора по возрасту, `site_id` — для разбиения, `participant_id` — для проверки уникальности. Возраст на момент сканирования служит приближением к возрасту при заполнении анкеты. Версии, респондент и допустимые коды описаны в [легенде ABIDE II](https://fcon_1000.projects.nitrc.org/indi/abide/ABIDEII_Data_Legend.pdf).

## Рабочая анкета сайта

Инструмент `workspace-questionnaire-v1`, одна завершённая анкета на строку. Ответы 0 — «не наблюдалось», 1 — «иногда», 2 — «часто», 3 — «почти всегда». Вариант 4 — «недостаточно наблюдений» — выгружается как JSON null. Суммарный балл РАС для этих вопросов не определён.

| Поле | Наблюдаемое действие |
|---|---|
| q0 | Предлагает совместную игру сверстникам |
| q1 | Присоединяется к занятию после приглашения |
| q2 | Обращается за помощью доступным способом |
| q3 | Поддерживает обмен репликами или жестами |
| q4 | Принимает изменение плана после объяснения |
| q5 | Переключается на новое правило с поддержкой |
| q6 | Сообщает о сенсорном дискомфорте |
| q7 | Выбирает тихое место во время шумных занятий |
| q8 | Выполняет знакомую инструкцию из двух шагов |
| q9 | Просит уточнить непонятную инструкцию |

## Игра сайта

Инструмент `workspace-party-v1`, одна завершённая сессия, восемь сцен. `choice0…choice6` — индекс выбранного сценарного ответа от 0 до 3. Это категории. Темы по порядку — новый друг, общая игрушка, эмоция при получении подарка, поддержка Эмили, изменение плана, новое правило и помощь другу. `emotion3` хранит отдельно выбранную эмоцию Эмили (0–3). Точные формулировки и порядок вариантов заданы в `src/features/game/party.ts`.

| Поле | Единица и трактовка |
|---|---|
| choice7 | Итог финальной последовательности: 0 — точный порядок, 1 — только первый верный шаг, 2 — без действий, 4 — иной вариант |
| seconds | Сумма зафиксированного времени сцен, секунды |
| changes | Сумма изменений выбора внутри одной фазы |
| help | Сумма повторов инструкции |

## Семейные задания

В двух инструментах `step0…step2` имеют разный смысл. В `family-questionnaire-v1` это инициирование общения, просьба о помощи в игре и присоединение к совместной игре. Код 0 — часто, 1 — иногда, 2 — пока не наблюдали. В `family-game-v1` это способы приветствия, помощь с упавшими карандашами и выбор занятия. Код — индекс варианта 0–2 в `src/pages/Family.tsx`. Объединять эти два задания можно по совпадающим псевдонимам ребёнка и назначения `assessment`. Текущие рабочие сессии сохраняются сайтом с перезаписью и не имеют идентификатора общего обследования.

## Происхождение

`participant` и `assessment` — HMAC с локальным ключом. В выгрузке нет имени, email, текста наблюдений или даты рождения. `local_demo` — автор или владелец с адресом домена демо. `local_unverified` означает, что происхождение остальных записей не подтверждено. `synthetic` — генератор. Для всех трёх источников `diagnosis=null`. Поле происхождения, отсутствие метки и разные инструменты сохраняются при экспорте.

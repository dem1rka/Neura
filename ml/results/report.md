В проверке по центрам модель правильно выделила 134 участников с РАС и 239 из группы сравнения. Ошибки — 10 пропущенных и 11 ложноположительных. Brier score — 0.037.

При повторной выборке целых центров диапазон 2,5–97,5 процентиля сбалансированной точности составил 90.4%–97.7%. Это ориентир разброса для имеющихся прогнозов; малое число центров ограничивает его точность.

Внешний цикл откладывает один центр целиком. Во внутреннем цикле оставшиеся центры по очереди служат валидацией. Кандидат выбирается по среднему ROC-AUC центров, порог — по их средней сбалансированной точности. Первичная строка объединяет прогнозы внешнего цикла. Строки по отдельным центрам показывают разброс. У логистической регрессии по сумме фиксирован порог 0,5. Внешняя проверка Yale относится только к этой регрессии.

Модель, переобученная на всех участниках ABIDE II: logistic_C1, порог 0.275. Каждый внешний цикл независимо выбирал кандидата и порог. Подробности приведены в metrics.json.

## Границы применения

Это ретроспективная классификация отобранных участников, а не прогноз будущего диагноза. Способы набора и подтверждения диагноза зависят от центра. TCD исключён: при наборе группы сравнения использовали SRS или SCQ. В OHSU клиницисты оценивали доступные клинические сведения, поэтому полная независимость диагноза от анкеты не установлена. Баллы модели нельзя интерпретировать как индивидуальный риск для семьи. Небольшие центры дают нестабильные оценки. Для дошкольников и для собственной анкеты и игры Neura нужна отдельная проверка на парных наблюдениях одного ребёнка с независимо полученной меткой.
